# Lcw332 Tap

## How do I install these formulae?

`brew install lcw332/tap/<formula>`

Or `brew tap lcw332/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "lcw332/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
